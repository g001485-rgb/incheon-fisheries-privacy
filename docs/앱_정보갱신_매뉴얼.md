## 4. 자료별 갱신 작업 카드

### 4.0 모든 카드에 공통인 절차

**원칙 1. 새 엑셀을 만들지 말고 작년 input 엑셀을 열어 값만 고친다.**
도구는 *시트 이름* 과 *1행의 열 제목* 이 정확히 같아야 돌아갑니다. 위도·경도는 수산현황 PDF에 없으므로 작년 엑셀의 좌표를 그대로 써야 합니다.

**원칙 2. 신규 항목은 좌표를 따로 확보한다.**
Google Earth Pro에서 위치를 찾아 마우스를 올리면 화면 아래에 위도·경도가 표시됩니다 (십진수로 보이게 설정: 도구 → 옵션 → 3D 보기 → 위도/경도 표시 → 십진수). 그 값을 엑셀에 적습니다. 예: 위도 `37.412382`, 경도 `126.605370`.

**원칙 3. 원본과 결과를 Drive에 남긴다.**
고친 엑셀은 `00_관리대장`, 만들어진 KML은 `01_KML`에 연도를 붙여 보관합니다. 예: `인천 어촌계 현황_2027.xlsx`.

**PDF에서 표를 꺼내는 방법** (수산현황 PDF 기준)

1. Acrobat에서 표 영역 선택 → 우클릭 → "선택 항목을 스프레드시트로 내보내기". 또는 한컴오피스로 PDF를 열어 표를 복사.
2. 꺼낸 표를 작년 엑셀 옆에 붙여 놓고 추가·삭제·변경된 행을 색으로 표시합니다.
3. 작년 엑셀의 **값만** 바꿉니다. 열 순서·열 이름·시트 이름은 건드리지 않습니다.

**템플릿형 도구 실행 방법** (4.3 ~ 4.9 공통)

폴더 구조는 7개 도구가 모두 같습니다.

```
incheon_fishing_app\tools\<자료명> kml 제작\
   input\           ← 엑셀을 여기에 (파일명 정확히)
   output\          ← 변환된 KML이 생김
   xlsx_to_kml.py
   사용법.txt
```

1. `input` 폴더에 엑셀을 넣습니다.
2. 실행합니다. 폴더 안에 `<자료명> KML 제작.exe`가 있으면 더블클릭. 없으면 명령 프롬프트에서:
   ```bat
   cd "%USERPROFILE%\Documents\incheon_fishing_app\tools\어촌계 kml 제작"
   python xlsx_to_kml.py
   ```
3. 화면에 `변환 완료: N개 (검증 통과)` 가 나오면 성공입니다. `output`에 KML이 생기고, **앱의 `assets\kml\` 폴더에 자동 복사**됩니다.
4. `[오류] …행의 '…' 값이 비어 있습니다` 같은 메시지가 나오면 지목된 행·열을 엑셀에서 고치고 다시 실행합니다.
5. `[경고] placemark N개 != 엑셀 M행` 이 나오면 결과를 쓰지 말고 엑셀을 점검합니다 (보통 아래쪽 빈 행이나 병합 셀).

**엑셀 작성 규칙** (공통)

- 값이 없으면 비우거나 `-` 를 넣습니다. 그 항목은 앱 상세창에서 빠집니다.
- `기타` 열: `라벨 : 값` 형식으로 한 줄에 하나씩 (셀 안에서 Alt+Enter로 줄바꿈).
- `이미지` 열: 사진 주소(`https://…`)를 한 줄에 하나씩. 사진은 6.2절 방법으로 먼저 올립니다.

| `면허어장 기본정보` | 관리기관, ID, 면허번호, 어업종류, 어업방법, 양식물, 어장위치, 면적(ha), 어업권자, 면허시작일, 면허종료일, 면허구분 |
| `면허어장 좌표정보` | ID, 위도(D), 경도(D), 좌표순번 |

- `ID`는 두 시트를 잇는 열쇠입니다 (예: `O-V-G-240`). 어장 하나에 좌표가 3줄 이상 있어야 합니다.
- `위도(D)`의 D는 십진수 도 단위입니다 (37.2197…). 대장이 도·분·초로 되어 있으면 `도 + 분/60 + 초/3600` 으로 환산합니다.
- `어업종류` 글자에 따라 지도 색이 정해집니다. **마을** = 자홍, **패류** = 노랑, **해조류** = 주황, **어류등** = 초록, **복합** = 파랑, **협동** = 군청. 이 단어들을 다른 말로 바꾸지 마세요.
- 날짜는 엑셀 날짜 형식 또는 `2029-01-05` 형태.

**절차**

1. `fishery_polygon_maker\input\` 폴더를 비우고 **엑셀 하나만** 넣습니다 (둘 이상이면 도구가 멈춥니다).
2. 실행:
   ```bat
   cd %USERPROFILE%\Documents\fishery_polygon_maker
   python make_polygons.py
   ```
   `완료 / KML 생성: …` 이 나오면 `output\<엑셀이름>.kml` 이 생깁니다. `건너뜀: ID=…, 좌표점 2개` 같은 줄이 있으면 그 어장은 빠진 것이니 좌표를 보충하고 다시 실행합니다.
3. **이 도구는 자동 복사를 하지 않습니다.** 파일 이름을 바꿔 앱 폴더로 복사합니다.
   ```bat
   copy "output\어업면허어장_옹진군_MASTER_270115.kml" "..\incheon_fishing_app\assets\kml\fishery_ongjin.kml"
   ```
4. 다른 군·구도 1~3을 반복합니다 (input 폴더를 비우고 다음 엑셀).
5. 5장(검수·배포)으로 갑니다.

**확인 포인트**: Google Earth Pro에서 output KML을 열어 어장이 바다 위 제자리에 있는지, 구역을 클릭하면 `1. 관리기관: … 9. 면허종료일: …` 설명이 뜨는지.

```xml

    <Data name="시설연도"><value>1973</value></Data>

    <Data name="위도"><value>37.150017</value></Data>
    <Data name="경도"><value>126.016750</value></Data>
    <Data name="icon_file"><value>사각어초.png</value></Data>
    <Data name="image_file"><value>reef_1.jpg</value></Data>
  </ExtendedData>
  <Point><coordinates>126.01675000,37.15001700,0</coordinates></Point>
</Placemark>
```

`icon_file`은 `assets\icons\reefs\` 안의 파일명, `image_file`은 사진 저장소 `reef_images\` 안의 파일명입니다. `icon_file`이 없으면 앱이 `어초종류` 글자로 아이콘을 찾고, 그래도 없으면 `default.png`를 씁니다.

## 6. 앱을 다시 배포하지 않아도 되는 작업

### 6.1 사용자 승인목록 (Google Sheet)

시트 「인천 해양수산 정보 서비스」 → 탭 `승인목록`. 사용자가 앱에 전화번호를 입력하면 앱이 이 시트를 조회합니다.

| 열 | 뜻 | 어떻게 다루나 |
| --- | --- | --- |
| phone_hash | 전화번호를 암호화(SHA-256)한 값 | **신규 사용자 추가 절차: [작성 필요 — Apps Script에 등록 기능이 있는지 전임자 확인]** |
| name, organization | 이름, 소속 | 그대로 입력 |
| mode | `official` 공무원 / `mudflat` 갯벌 어업인 / `vessel` 어선 어업인 | 앱 화면 구성이 달라지므로 정확히 |
| approved | `Y`만 이용 가능 | **승인 취소**는 `N`으로 바꿉니다 (행 삭제보다 기록이 남아 좋습니다) |
| device_id, device_registered_at | 첫 로그인 기기 정보가 자동 기록됨 | **기기 변경 요청**이 오면 `device_id` 칸을 비웁니다. 다른 기기로 로그인하면 "이미 다른 기기에서 등록된 번호"가 뜨는 것이 정상 동작입니다 |
| region, memo, user_type_note, updated_at | 관리용 메모 | 자유 |

나머지 탭 3개(위치저장·자율관리·조업관리 제출)는 앱의 「관리자 제출」 기능이 쌓는 곳입니다. 편집하지 않습니다.

### 6.2 사진 올리기 (GitHub `incheon-reef-images`)

| 폴더 | 용도 | 파일 이름 |
| --- | --- | --- |
| `reef_images/` | 인공어초 상세 사진 | `reef_<시설ID>.jpg`, 여러 장이면 `reef_<ID>_1.jpg` … (엑셀 `image_file`과 같게) |
| `tourism_images/` | 해수욕장·어촌체험마을 사진 | `beach_01.png`, `village_01.jpg` 등 (엑셀 `이미지` 열 주소와 같게) |

1. 사진 크기를 줄입니다. 긴 변 1200px, 300KB 이하를 권합니다 (앱은 작게 보여 줍니다).
2. GitHub 웹에서 저장소 → 해당 폴더 → **Add file → Upload files** → 끌어다 놓기 → Commit changes.
3. 앱에서 쓰는 주소는 `https://cdn.jsdelivr.net/gh/g001485-rgb/incheon-reef-images@main/<폴더>/<파일이름>` 입니다. 브라우저에 붙여 넣어 사진이 보이면 정상입니다 (처음엔 몇 분 걸릴 수 있음).
4. **사진을 바꿀 때는 같은 이름으로 덮어쓰지 말고 새 이름을 씁니다.** 같은 이름이면 이미 사진을 받은 기기에는 옛 사진이 계속 보입니다. 새 이름을 쓰면 엑셀의 파일 이름도 고쳐야 하고, 그 경우는 앱 재배포가 필요합니다.

### 6.3 개인정보처리방침 (문의처 · 시행일)

GitHub `incheon-fisheries-privacy` 저장소의 `privacy-policy.html`이 스토어에 등록된 방침 페이지입니다. 담당자가 바뀌면:

1. GitHub 웹에서 파일 열기 → 연필 모양(편집) → 10장 문의처의 이름·전화, 맨 아래 시행일 수정 → Commit changes.
2. 몇 분 뒤 웹페이지에 반영됩니다. Play Console에 등록된 주소는 바꿀 필요가 없습니다.

### 6.4 실시간 자료 (조석 · 날씨 · 수온)

평소 손댈 것은 없습니다. 다만 **공공데이터포털 인증키가 만료되면 조석·날씨가 한꺼번에 멈춥니다.** 만료 전에 포털에서 연장하면 키 값이 그대로라 앱 수정이 필요 없습니다. 키가 바뀌면 코드 수정이 필요합니다 (8.3절).

## 8. 코드 수정이 필요한 작업

엑셀·도구만으로는 안 되고 코드를 고쳐야 하는 일입니다. 개발자가 없으면 **Claude Code 같은 AI 코딩 도구에 저장소와 이 매뉴얼을 주고 아래 문장을 그대로 요청**해도 됩니다. 요청 뒤에는 5장 검수를 똑같이 합니다.

### 8.1 어촌계 상세창에 어촌계장·전화번호 표시

`tools\_generator\gen_tools.py` 의 `LAYERS` 목록에서 어촌계 항목을 고칩니다.

- `fields=[]` → `fields=["어촌계장", "전화번호"]`
- `name_as_field="None"` → `name_as_field='"어촌계"'`

그 뒤 그 폴더에서 `python gen_tools.py` 를 실행하면 `tools\어촌계 kml 제작\xlsx_to_kml.py` 가 다시 만들어집니다. 이후에는 4.3 카드대로 하면 됩니다. (실행파일 `.exe`를 쓰고 있다면 PyInstaller로 다시 만들어야 합니다.)

### 8.2 해양수산 담당자 연락처 레이어 추가

요청 문장 예:

> `tools/_generator/gen_tools.py`의 LAYERS에 「담당기관 kml 제작」 도구를 추가해 줘. 엑셀 `인천 해양수산 담당기관 연락처.xlsx`, 시트 `담당기관`, 이름 열 `기관`, 그룹 열 `기관`, 상세 열 `부서, 담당업무, 담당자, 전화번호, 팩스, 주소`, 출력 `fisheries_office_contact.kml`. 그리고 `lib/map/kml_layer_registry.dart`에 id `fisheries_office_contact`, 제목 `해양수산 담당기관`, 카테고리 `otherInfo`, infoType `generic` 으로 레이어를 등록해 줘. 상세창에서 전화번호 형식 값은 탭하면 전화가 걸리도록 `tel:` 링크로 표시해 줘.

### 8.3 그 밖에 코드 수정이 필요한 경우

| 상황 | 고칠 파일 |
| --- | --- |
| 공공데이터포털 인증키가 바뀜 | `lib\core\config\api_keys.dart` |
| Google Maps 키가 바뀜 | `android\app\src\main\AndroidManifest.xml` |
| 국립해양조사원 관측소 추가·폐지 (수온·조석) | `lib\features\weather\_sea_temperature_stations.dart`, `lib\features\tide\tide_api_service.dart` |
| 새 지도 레이어 추가 | `lib\map\kml_layer_registry.dart` + `tools\_generator\gen_tools.py` |
| 면허어장 색 체계 변경 | `fishery_polygon_maker\make_polygons.py` 의 `FISHERY_STYLE` **과** 앱 `lib\map\map_legend_panel.dart` 를 함께 |
| 해양보호구역 레이어 표시 (파일은 있으나 미등록) | `lib\map\kml_layer_registry.dart` 에 `marine_protected_area` 등록 |

### 8.4 정리해 두면 좋은 것 (선택)

- Apps Script 소스를 편집기에서 복사해 `incheon_fishing_app\tools\apps_script\` 에 보관 (승인 로직 백업).
- 「인공어초 kml 제작」 도구 폴더를 저장소에 넣기 (`tools\.gitignore` 에서 해당 줄 삭제).
- 쓰지 않는 파일 삭제: `lib\map\drive_csv_sync_service.dart`, `version.json` (혼동 방지).
