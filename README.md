# 조개류생산동 작업일지 만들기

손으로 적은 작업일지 사진을 올리면 글자·숫자를 읽어 내용을 채우고,
확인·수정한 뒤 **A4 작업일지 PDF** 로 저장하는 웹 앱입니다.

설치할 것이 없습니다. `index.html` 을 브라우저로 열면 바로 쓸 수 있습니다.

## 쓰는 순서

1. **사진 올리기** — 작업일지를 찍은 사진을 끌어다 놓거나 눌러서 고릅니다.
   휴대폰에서는 바로 촬영할 수 있습니다.
2. **글자 인식 실행** — 사진에서 읽은 내용이 아래 입력칸에 채워집니다.
   원문 그대로도 볼 수 있고, 고쳐서 다시 채울 수도 있습니다.
3. **내용 확인 및 수정** — 손글씨는 잘못 읽힐 수 있으니 반드시 확인합니다.
   오른쪽 미리보기가 고치는 대로 바뀝니다.
4. **PDF 만들기** — `작업일지_2026-09-12.pdf` 형식으로 내려받습니다.
   `인쇄` 로 바로 뽑거나, `JSON 내보내기` 로 내용만 따로 보관할 수도 있습니다.

## 담는 항목

원본 양식(조개류생산동 작업내용)의 칸을 그대로 옮겼습니다.

| 구역 | 내용 |
| --- | --- |
| 작업일 | 년 / 월 / 요일 (요일은 날짜에서 자동 계산) |
| 식물플랑크톤 접종 | 단지(10ℓ) · 아크릴(500ℓ) · 대형(14톤) |
| 먹이 공급 | 모패 관리실 · 치패 사육실 · 유생 사육실 — 사육품종, 수조번호, 먹이 종류·수량 |
| 기타 주의사항 | 자유 항목 (필요한 만큼 추가) |

여러 줄에 같은 먹이를 주는 경우에는 각 사육실의 **공통 먹이** 칸에 적으면
원본처럼 한 칸으로 묶여 표시됩니다.

## 홈 화면에 추가해서 쓰기

`https` 주소로 열면 **홈 화면에 추가**할 수 있습니다. 추가하면 주소를 칠 필요 없이
아이콘만 눌러서 앱처럼 열리고, 주소창 없이 전체 화면으로 뜹니다.

- 안드로이드(크롬): 위쪽에 뜨는 `홈 화면에 추가` 버튼을 누르거나, 메뉴(⋮) → `홈 화면에 추가`
- 아이폰(사파리): 아래 공유 버튼(⬆) → `홈 화면에 추가`

한 번 열어두면 앱 파일이 기기에 저장되어 **인터넷이 끊겨도 열리고 PDF도 만들어집니다.**
글자 인식만 인터넷이 필요합니다.

## 개인정보 · 오프라인

- 사진과 입력 내용은 **브라우저 밖으로 나가지 않습니다.** 서버로 올리지 않습니다.
- 입력 내용은 쓰던 브라우저에만 자동 저장됩니다 (`localStorage`).
  다른 기기로 옮길 때는 `JSON 내보내기` / `JSON 불러오기` 를 씁니다.
- PDF 생성에 쓰는 라이브러리는 `vendor/` 에 함께 넣어 두어 **인터넷 없이도 PDF가 만들어집니다.**
- 글자 인식(OCR)만 용량이 커서 필요할 때 내려받습니다. 인터넷이 없으면
  인식 버튼이 잠기고, 직접 입력해서 PDF를 만드는 길은 그대로 열려 있습니다.

## 인식 정확도에 대해

한글 손글씨는 인쇄체보다 인식률이 크게 떨어집니다. 이 앱은 인식 결과를
**초안**으로만 다루며, 읽어내지 못한 칸은 비워 두고 이미 적어둔 내용은 지우지 않습니다.
잘 읽히게 찍으려면:

- 양식 전체가 화면에 꽉 차게, 기울지 않게 찍습니다.
- 형광등 반사가 글씨를 가리지 않게 각도를 조금 틀어 찍습니다.
- 초점이 흐리면 다시 찍습니다.

날짜, 먹이 코드(`Ph8`, `T4`, `I8`, `Pv4` 등), 수조번호처럼
숫자·영문이 섞인 부분이 비교적 잘 읽힙니다.

## 파일 구성

```
index.html                 화면
css/styles.css             모양 (입력 화면 + A4 양식 + 인쇄)
js/model.js                작업일지 데이터 구조, 예시 내용
js/ocr.js                  사진 전처리 · 문자 인식 · 칸 나누기
js/app.js                  입력 반영, 미리보기, PDF 저장
vendor/                    html2canvas, jsPDF (함께 배포)
sw.js                      앱을 기기에 저장 (인터넷 없이 열기)
manifest.webmanifest       홈 화면 추가용 앱 정보
icons/                     앱 아이콘
sample/sample-worksheet.jpg  예시 작업일지 사진
```

## 웹에 올려서 쓰기

정적 파일뿐이라 아무 정적 호스팅(GitHub Pages 등)에 그대로 올리면 됩니다.
카메라 · 홈 화면 추가 · 오프라인 저장은 모두 `https` 에서만 동작하니,
휴대폰에서 쓸 계획이면 `https` 주소로 올리세요. 로컬에서 열어볼 때는 간단한 서버 하나면 됩니다.

```sh
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```
